# Парсер south-meridian.ru

Команда готовит XLSX для существующего импорта товаров в админке Новатех.
Она не изменяет базу данных, не ставит задания в очередь и ничего не публикует.

## Запуск

Из корня backend-проекта с установленными `requirements.txt`:

```powershell
python manage.py parse_south_meridian --refresh
```

Результаты:

- `artifacts/south-meridian/products.xlsx`: активный лист `Products` готов для импорта.
- `artifacts/south-meridian/products.report.json`: полные данные, источники и ошибки.
- `artifacts/south-meridian/cache/`: локальные копии HTML для повторного запуска и диагностики.

Собранные данные и кеш исключены из Git. При повторном запуске без `--refresh`
используется кеш HTML; доступность файлов и актуальный robots.txt проверяются заново.

Дополнительные параметры:

```powershell
python manage.py parse_south_meridian --output artifacts/sms.xlsx --delay 0.5 --timeout 30
python manage.py parse_south_meridian --brand "SAMSUN MAKINA (SMS)"
```

`--publish` выставляет `is_hidden=false` только у строк без замечаний. Сам импорт
при этом все равно не запускается. `--skip-media-check` предназначен для отладки:
ссылки сохраняются, но проверка файлов пропускается, соответствующий лист пустой.

## Что Собирается

Обход использует sitemap и ссылки каталога, включая дочерние страницы и скрытые
вкладки. Контакты, проекты, боковое меню и подвал не становятся товарами.

Поддерживаются все пять категорий:

- Трубы из высокопрочного чугуна: отдельная карточка каждой серии.
- Фитинги: каждая вкладка становится отдельной позицией со своей фотографией.
- Насосы: опубликованная серия насосов, без выдуманных размерных модификаций.
- Запорно-регулирующая арматура: отдельные типы и варианты, включая подвиды задвижек и обратных клапанов.
- Прочее оборудование: гидранты и крышки люков раздельно.

Поля: название, категория, производитель, описание, технический HTML с таблицами,
явно указанные характеристики `char_*`, фотографии, видео, прямые PDF-ссылки,
SEO-заголовки. Исходные URL и идентификаторы блоков остаются в справочных колонках.
Полноразмерные фотографии берутся из ссылок или srcset; дубли миниатюр и видео
с техническими query-параметрами удаляются. Если источник дал только миниатюру,
парсер не выдумывает адрес оригинала.

Проверка файлов выполняет HEAD, проверяет MIME и размер в пределах лимита импорта
100 МБ. При последующем импорте существующий загрузчик скачивает файлы в наше
хранилище. Сами картинки не встраиваются в XLSX.

## Ограничения Данных

- Заводских артикулов нет: генерируются стабильные 12-значные численные идентификаторы.
  Это не случайная генерация при каждом запуске. Повторный импорт обновляет позиции
  по SKU. Если поставщик поменяет URL/идентификатор вкладки/фотографию варианта,
  соответствие нужно проверить вручную.
- Цен и остатков нет: `price=0`, `currency=RUB`, `available=false`.
- По умолчанию все строки скрыты (`is_hidden=true`) до проверки в админке.
- Производитель по умолчанию SAMSUN MAKINA (SMS), указанный поставщиком; это не
  бренд «Южный Меридиан». Для существующего производителя можно передать его
  имя или slug через `--brand`.
- Общие характеристики родительской страницы труб сохранены на листе `Категории`,
  но не навязываются каждой серии: например, покрытия разных серий различаются.
- Общие папки сертификатов/каталогов/технической документации на Яндекс Диске
  сохранены на справочном листе. Они не являются файлами сертификатов конкретного
  товара и автоматически ко всем карточкам не привязываются.
- Лист `Категории` содержит фотографии и контент групп для справки. Текущий импорт
  читает только `Products`, создает/находит группы по имени, но не загружает их
  фотографии из дополнительных листов. Для существующих групп при необходимости
  замените `group_slug` на их реальные slug перед импортом.
- На источнике у одного обратного клапана скопировано описание игольчатого.
  Исходный текст сохранен, добавлено замечание; даже с `--publish` позиция скрыта.

При сетевой ошибке, неподдерживаемой категории, несовпадении вкладок или недоступном
файле команда возвращает ошибку и пишет JSON-отчет. Новый XLSX не создается;
существующий XLSX остается от предыдущего успешного запуска. Превышение лимита
ячейки Excel также вызывает ошибку, а не молчаливое обрезание контента.

## Проверка

```powershell
python manage.py check
python manage.py test shop.tests_south_meridian shop.tests_south_meridian_http
```

Проверены разделение товаров, неактивные вкладки, принадлежность фотографий,
таблицы и характеристики, очистка HTML, формулы Excel, robots.txt, техническая
cookie, кеш, ограничение домена и редиректов, повторные попытки, MIME/размер файлов,
идемпотентный импорт через штатный сервис.

Проверка живого сайта 06.09.2026: 33 позиции (6 трубных серий, 14 фитингов,
1 серия насосов, 10 позиций арматуры, 2 позиции прочего оборудования).
Реальный импорт в изолированную тестовую БД создал 33 товара, 5 групп,
79 изображений и 18 видео, без пропусков и предупреждений загрузчика.
Общие сертификаты намеренно не импортировались. Прод не изменялся.

Все 27 новых тестов проходят. Общий `shop.tests`: 137 тестов, из них 4 падения
проверок старого поиска и 1 ошибка старого теста админки (`cleaned_html` не объявлен).
Эти же 5 проблем подтверждены на исходном коммите `42e1719` без парсера.
